# L-CAP: Long-Term AI Collaboration Protocol 🛡️

**Deterministic Context Management & Semantic Continuity for LLMs.**

L-CAP (v1.1-alpha) — это открытый методологический протокол, разработанный для устранения **контекстной деградации** в длительных сессиях взаимодействия с ИИ (30+ сообщений). 

## 1. Проблема: Эффект «Золотой рыбки»
При длительной работе модель накапливает логический шум, теряет фокус на первичных задачах и поддается «дрейфу внимания». L-CAP решает это через дискретное управление памятью и верифицированные точки восстановления.

## 2. Ключевые концепции
Протокол переводит хаотичный чат в структурированную инженерную сессию:

*   **Snapshot (Слепок):** Дистиллированный конспект эволюции смыслов, фиксирующий траекторию мысли.
*   **Hard Reset (Сброс):** Инициализация чистой сессии для обнуления энтропии.
*   **Notary (Нотариус):** Роль ИИ в новой сессии, принимающей «Слепок» как единственный источник истины (T-0).

## 3. Архитектура данных (Field Log)
Каждое решение в рамках L-CAP размечается объективными метриками:
- **Global MSG-Index:** Сквозная нумерация реплик сквозь все чаты.
- **MSG-Delta (D):** Дистанция обсуждения. Количество сообщений, затраченных на тезис = «физический вес» и верифицированность решения.
- **Custom Metrics:** Возможность внедрения кастомных тегов (`[Fuel: Calc]`, `[Mood: Focus]`).
- **Exceptions Registry:** Реестр тупиковых путей (Rejected/Blocked) для предотвращения цикличных ошибок.

## 4. Быстрый старт (Quick Start)
Для миграции контекста используйте триггер:
> `L-CAP TRIGGER: Generate Snapshot for Migration.`

**Пример инъекции в новый чат:**
```text
[MSG 01-15 | D: 14 | Tech] CORE: Архитектура микросервисов утверждена.
[MSG 16-35 | D: 19 | UI] STYLE_LOCK: Переход к темной теме, отказ от скруглений.
[REJECTED]: Использование React Native (выбран Flutter).
```

## 🌍 True Story: Как это появилось
L-CAP родился не в офисе, а во время планирования большой одиночной мото-экспедиции: **Владивосток — Магадан — Байкал — Монголия — Алтай**.

Проект был сложным: погодные окна, графики ТО, логистика запчастей и границы. На 40-м сообщении мой ИИ-ассистент начал «сдавать»: путал интервалы обслуживания и забывал про утвержденные точки маршрута. 

Мне нужно было решение, чтобы не потерять наработки месячного планирования. Так появился этот метод «сброса и дистилляции». Если протокол помог справиться с логистикой через полконтинента, он справится почти с любой сложной инженерной или творческой задачей.
